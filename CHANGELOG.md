# Changelog

All notable changes to docuconf for PHP (`docuconf/docuconf`) are documented here. Entries after 0.1.0 are
generated by [release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for PHP apps on
[vlucas/phpdotenv](https://github.com/vlucas/phpdotenv), implementing spec `v1alpha1`.

### Features

* Declarations in phpdotenv's style of every environment variable and file input, with types, rules, descriptions
  and secrets.
* Boot validation that reports every problem at once, one line each, with stable error codes and never a secret
  value.
* Contract export to `contract.cue` (formatted as `cue fmt` does) with the `docuconf` CLI, and the shared
  conformance runner.
* Laravel integration (service provider, `php artisan docuconf:export`) and Symfony integration (bundle,
  `bin/console docuconf:export`).
* The `orders` example on Laravel and on Symfony.
